## Описание проекта

Во втором задании сервис из первого задания переписан на веб-фреймворке FastAPI с использованием слоистой архитектуры и внедрения зависимостей.

### Предметная область:
- **Пользователи (User)**:
  - `RegularUser`: обычный тариф, может арендовать не более 1 самоката одновременно.
  - `VipUser`: VIP-тариф, может арендовать до 3 самокатов одновременно.
- **Самокаты (Scooter)**:
  - Имеют заряд батареи (0–100%) и статус (`available`, `rented`, `maintenance`).
- **Операции предметной области**:
  - Аренда (`POST /api/scooters/{id}/rent`): проверяет доступность, минимальный заряд от 20% и лимит тарифа пользователя.
  - Возврат (`POST /api/scooters/{id}/return`): завершает поездку, списывает заряд. Если заряд упал ниже 20%, самокат переходит в статус `maintenance`.
  - Зарядка (`POST /api/scooters/{id}/charge`): пополняет батарею до 100%. Самокат в поездке заряжать нельзя.
  - Изменение заряда через обычный `PUT /api/scooters/{id}` во время поездки запрещено.

## Архитектура проекта

Проект разделен на слои:
1. **Контроллеры (`app/routers/`)**: эндпоинты FastAPI для пользователей и самокатов.
2. **Внедрение зависимостей (`app/dependencies.py`)**: передача сервиса в роутеры через `Depends()`.
3. **DTO и валидация (`app/schemas.py`)**: Pydantic-модели для проверки входящих данных.
4. **Бизнес-логика (`app/service.py`)**: сервис с доменными правилами, получает репозиторий через конструктор.
5. **Хранилище данных (`app/repository.py`)**: хранение объектов в памяти (`InMemoryRepository`).
6. **Доменные модели (`app/models.py`)**: классы предметной области.

---

## Основные эндпоинты

- `GET /ping` — проверка работы сервиса
- `GET /` — краткая информация о сервисе
- `GET /docs` — интерактивная документация Swagger UI
- `GET, POST /api/users` — список и создание пользователей (фильтрация по `?type=vip|regular`)
- `GET, PUT, DELETE /api/users/{id}` — получение, редактирование и удаление пользователя
- `GET, POST /api/scooters` — список и создание самокатов (фильтрация по `?status=...&min_charge=...`)
- `GET, PUT, DELETE /api/scooters/{id}` — получение, редактирование и удаление самоката
- `POST /api/scooters/{id}/rent` — аренда самоката
- `POST /api/scooters/{id}/return` — возврат самоката
- `POST /api/scooters/{id}/charge` — зарядка самоката

## Запуск и проверка

### 1. Запуск сервера
```bash
python3 main.py
```
Сервер запустится на `http://localhost:8080`.
Документация Swagger доступна по адресу `http://localhost:8080/docs`.

### 2. Запуск тестов
Юнит-тесты проверяют логику сервиса и репозитория напрямую без запуска веб-сервера:
```bash
python3 -m unittest discover tests
```

### 3. Проверка curl-запросами
В отдельном терминале запустите:
```bash
./requests.sh
```
