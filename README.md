## 1. Описание предметной области

Сервис моделирует систему проката электросамокатов.

### Ресурсы и их связь:
1. **Пользователь (`User`)**:
   - `id`: уникальный идентификатор
   - `name`: имя пользователя
   - `user_type`: тип тарифа (`regular` или `vip`)
   - `rented_scooter_ids`: список ID самокатов, находящихся в текущей аренде
2. **Электросамокат (`Scooter`)**:
   - `id`: уникальный идентификатор
   - `model`: модель
   - `charge_level`: уровень заряда (0–100%)
   - `status`: текущий статус (`available`, `rented`, `maintenance`)
   - `current_user_id`: ID пользователя, который сейчас арендует самокат (или null)

Связь: пользователь арендует самокаты (у самоката фиксируется `current_user_id`, а у пользователя — список `rented_scooter_ids`).

### Типы с различающимся поведением:
У ресурса `User` реализовано два типа:
- **`RegularUser` (`user_type: "regular"`)**: стандартный тариф. Может одновременно арендовать не более **1** самоката (`max_rentals = 1`).
- **`VipUser` (`user_type: "vip"`)**: премиальный тариф. Может одновременно арендовать до **3** самокатов (`max_rentals = 3`).

### Доменные операции:
1. **`POST /api/scooters/{id}/rent`** — аренда самоката:
   - Проверяет существование самоката и пользователя (404).
   - Самокат должен быть в статусе `available` (409 при занятости/ТО).
   - Заряд самоката должен быть не менее 20% (422 при низком заряде).
   - Пользователь не должен превышать лимит своего тарифа (422 при исчерпании лимита).
   - Самокат переходит в статус `rented`, привязывается к пользователю.
2. **`POST /api/scooters/{id}/return`** — возврат самоката:
   - Самокат должен быть в статусе `rented` (409 если нет).
   - Списывает переданный расход батареи `battery_used`.
   - Если остаток заряда < 20%, самокат переходит в `maintenance` (на техобслуживание / зарядку), иначе в `available`.
   - Самокат отвязывается от пользователя.
3. **`POST /api/scooters/{id}/charge`** — подзарядка аккумулятора:
   - Нельзя заряжать самокат во время поездки (409).
   - Заряд пополняется до 100%. При заряде >= 20% статус `maintenance` сменяется на `available`.

### Фильтрация списков:
- Самокаты:
  - `GET /api/scooters?status=available`
  - `GET /api/scooters?min_charge=50`
  - `GET /api/scooters?status=available&min_charge=70`
- Пользователи:
  - `GET /api/users?type=vip`
  - `GET /api/users?type=regular`

## 2. Спецификация API

| Метод | Путь | Описание | Коды ответов |
|---|---|---|---|
| `GET` | `/ping` | Проверка работоспособности сервиса | 200, 405 |
| `GET` | `/api/users` | Список пользователей (фильтр `?type=...`) | 200 |
| `POST` | `/api/users` | Создание пользователя | 201, 400 |
| `GET` | `/api/users/{id}` | Получение пользователя по ID | 200, 404 |
| `PUT` | `/api/users/{id}` | Редактирование пользователя | 200, 400, 404, 422 |
| `DELETE` | `/api/users/{id}` | Удаление пользователя (запрещено при активной аренде) | 200, 404, 422 |
| `GET` | `/api/scooters` | Список самокатов (фильтры `?status=...`, `?min_charge=...`) | 200, 400 |
| `POST` | `/api/scooters` | Создание самоката | 201, 400 |
| `GET` | `/api/scooters/{id}` | Получение самоката по ID | 200, 404 |
| `PUT` | `/api/scooters/{id}` | Редактирование самоката | 200, 400, 404 |
| `DELETE` | `/api/scooters/{id}` | Удаление самоката (запрещено во время аренды) | 200, 404, 422 |
| `POST` | `/api/scooters/{id}/rent` | Доменная операция: аренда самоката (`{"user_id": 1}`) | 200, 400, 404, 409, 422 |
| `POST` | `/api/scooters/{id}/return` | Доменная операция: возврат самоката (`{"battery_used": 15}`) | 200, 400, 404, 409 |
| `POST` | `/api/scooters/{id}/charge` | Доменная операция: подзарядка (`{"amount": 50}`) | 200, 400, 404, 409 |

## 3. Структура проекта

```text
scooter-rental-service/
├── .vscode/
│   ├── launch.json       # Конфигурация запуска F5 в VS Code
│   └── settings.json     # Настройки редактора
├── app/
│   ├── __init__.py
│   ├── exceptions.py     # Доменные исключения (400, 404, 409, 422)
│   ├── models.py         # Модели User, RegularUser, VipUser, Scooter
│   ├── service.py        # Бизнес-логика и хранилище в памяти (не зависит от HTTP)
│   └── server.py         # HTTP-обработчик на базе http.server и json
├── tests/
│   ├── __init__.py
│   └── test_service.py   # Модульные тесты на unittest
├── pyproject.toml        # Конфигурация Poetry / uv
├── requests.sh           # Скрипт с curl-запросами всех операций и ошибок
├── main.py               # Точка входа для запуска HTTP-сервера
└── README.md
```

## 4. Запуск и тестирование

### Запуск сервера
```bash
python3 main.py
```
Сервер будет доступен по адресу `http://localhost:8080`.

### Проверка запросов curl
В отдельном окне терминала выполните:
```bash
./requests.sh
```

### Запуск модульных тестов
```bash
python3 -m unittest discover tests
```

### Запуск в Visual Studio Code
1. Откройте папку проекта `scooter-rental-service` в VS Code.
2. Нажмите `F5` для запуска сервера с отладкой.
3. В терминале запустите `./requests.sh` для проверки всех сценариев.
